Java Finance Manager


A beginner friendly console application for tracking income and expenses, written in Java.

Features
 Add income and expense transactions
 View transaction history and delete transactions by ID
 See total income, total expenses, and current balance
 Summarize expenses by category
 Automatically save and reload transactions from a local text file

This app creates a transactions.txt file 


Learning goals
Java OOP, constructors, encapsulation, enums, lists, maps, exception handling, file I/O


Note: this is a fun project I did just to test out new things I've learned.
